# 📱 PhoneCompte — Site 3D de vente de smartphones

Site Next.js premium avec :

- 🎮 **Téléphone 3D en Three.js** qui tourne au scroll et suit la souris/le doigt
- ✨ **Animations au scroll** partout (Framer Motion) : fade, parallaxe, rotations 3D
- 📱 **Design mobile-first** : menu burger animé, grille responsive, vibrations tactiles
- 🛍️ **Boutique complète** : filtres de gamme, cartes produits, panier fonctionnel
- 💎 UI glassmorphism, fond aurora animé, bandeau défilant, avis clients, footer

## 🚀 Lancer le site

```bash
npm install     # la première fois
npm run dev     # puis ouvrir http://localhost:3000
```

## 📂 Structure

```
app/            → layout, page d'accueil, styles globaux
components/     → Navbar, Hero (+ PhoneScene 3D), Marquee, Features,
                  Products, Showcase, Testimonials, CTA, Footer
```

## 🛠️ Stack

Next.js 14 (App Router) · Tailwind CSS 3 · Three.js · Framer Motion
